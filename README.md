# Silicon vs silicon nitride for free-electron–light coupling: a simulation study

**Status:** project skeleton only. There are no physics results yet.

## Research question
For telecom-wavelength waveguides, does Si or Si₃N₄ give stronger electron–light
coupling, and does the answer differ between laser-driven (classical) coupling
and spontaneous single-photon (quantum) coupling?

## Install
Requires Python 3.10 or newer.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install -e .
pytest
```
